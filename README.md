A token-launch radar for make.fun's "Build the best token launch radar" bounty. It ranks 200 of the 758 snapshot protocols — the watchlist first, then the rest by an implied value derived from each protocol's own TVL, seven-day growth and days listed without a token. Every row carries a costed farm plan, and the dashboard ships as a static board with a detail view and an out-of-sample evidence panel.

## Run it

```sh
mkdir -p out && node main.ts --input input/snapshot.json --output out
```
